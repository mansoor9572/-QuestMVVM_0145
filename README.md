# QuestMVVM App

An Android application built with Jetpack Compose implementing MVVM architecture, StateFlow, and Navigation Compose for student registration and details display.

## Features
- **Form Pendaftaran (Form Screen)**: Input student full name, gender selection via RadioButton, and address.
- **Data Siswa (Detail Screen)**: Summary view displaying submitted student details.
- **MVVM Architecture**: Clean separation of concerns with `SiswaViewModel` and state management.
- **Navigation Compose**: Seamless navigation between input form and detail view.
